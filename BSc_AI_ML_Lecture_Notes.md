# WEEK 1 — INTRODUCTION TO ARTIFICIAL INTELLIGENCE

## 1.1 Introduction

Artificial Intelligence (AI) is a field of computing concerned with creating systems capable of performing tasks that normally require some form of human intelligence.

The source material describes AI as technology that enables computers and machines to replicate aspects of human intelligence.

AI systems may be designed to:

* Perceive their environment
* Understand information
* Learn from experience
* Reason about problems
* Make decisions
* Understand language
* Recognize images
* Plan actions
* Generate content
* Interact with humans
* Act autonomously

---

## 1.2 What is Intelligence?

Intelligence involves the ability to:

* Learn
* Understand
* Reason
* Solve problems
* Adapt
* Make decisions
* Recognize patterns
* Communicate
* Plan

Human intelligence is biological, while artificial intelligence attempts to reproduce selected intelligent capabilities using computational systems.

---

## 1.3 Characteristics of AI

Important characteristics include:

### 1. Learning

AI systems can learn patterns from data.

### 2. Reasoning

AI can use available information to reach conclusions.

### 3. Problem Solving

AI can search through possible solutions.

AI can determine sequences of actions needed to achieve goals.

## 1.5 History of AI

The development of AI can be viewed through several periods:

### Early Foundations

AI grew from mathematics, logic, philosophy, neuroscience and computer science.

### Early AI Research

Researchers explored symbolic reasoning, theorem proving, game playing and problem solving.

AI increasingly shifted from manually programmed rules toward systems that learn patterns from data.

Large datasets and powerful GPUs enabled deep neural networks to achieve strong results in vision, speech and language.

### Generative AI Era

Modern AI systems can generate text, images, audio, video and software.

# WEEK 2 — AI, MACHINE LEARNING, DEEP LEARNING AND LEARNING PARADIGMS

## 2.1 AI vs ML vs DL

AI is the broad field.

Machine Learning is a subset of AI.

Deep Learning is a subset of Machine Learning.

The source defines ML as a subset of AI that learns patterns from data and makes predictions or decisions without explicit programming for every task.

Deep learning uses neural networks with multiple layers to learn complex representations.

Conceptually:

**AI → Machine Learning → Deep Learning**

---

## 2.2 Machine Learning

Traditional programming:

**Data + Rules → Output**

Machine learning:

**Data + Expected Outputs → Learned Model**

After training:

**New Data + Model → Prediction**

---

# 2.3 Learning Paradigms

## Supervised Learning

The model learns from labelled data.

Example:

| Hours Studied | Exam Result |
| ------------: | ----------- |
|             2 | Fail        |
|             5 | Pass        |
|             8 | Pass        |

The model learns a relationship between input and output.

Applications:

* Classification
* Regression
* Medical diagnosis
* Spam detection

The source describes supervised learning as training using labelled datasets to learn mappings between inputs and outputs.

---

## Unsupervised Learning

The dataset contains no target labels.

The algorithm discovers patterns or structures.

Examples:

* Customer segmentation
* Clustering
* Anomaly detection
* Dimensionality reduction

The source identifies K-Means, PCA, hierarchical clustering and DBSCAN among unsupervised-learning methods.

---

## Semi-Supervised Learning

Uses:

* Small labelled dataset
* Large unlabelled dataset

This is useful when labelling data is expensive.

The source explicitly describes semi-supervised learning as combining labelled and unlabelled data.

---

# 2.4 Self-Supervised Learning

Self-supervised learning is particularly important in modern AI.

The system creates learning signals from the data itself rather than relying entirely on manually labelled examples.

For example, given:

> "Artificial intelligence is a field of ______."

The model may learn to predict the missing word.

Another example is:

* Input: an image
* Task: predict a transformed or hidden part of the image

Self-supervised learning is widely useful because large quantities of unlabelled data are available while manual labelling can be expensive.

### Typical stages

1. Collect unlabelled data.
2. Construct a pretext learning task.
3. Train a representation model.
4. Learn useful features.
5. Fine-tune using labelled data.

---

# 2.5 Reinforcement Learning

An agent interacts with an environment.

The agent:

1. Observes a state.
2. Selects an action.
3. Receives a reward.
4. Moves to another state.
5. Learns a policy.

The source describes reinforcement learning as learning through interaction with an environment using feedback.

---

## 2.6 Transfer Learning

Transfer learning adapts knowledge learned on one task to another related task.

For example:

A model trained on a large image dataset can be adapted to recognize plant diseases.

The source identifies transfer learning as adapting a model trained for one task to another related task.

---

## 2.7 Cognitive Computing

Cognitive computing attempts to reproduce human-like information processing and reasoning.

It may involve:

* Natural language

* Learning
* Context understanding
* Decision support

An autonomous system can:

* Perceive

# WEEK 5 — AI PROBLEM SOLVING AND SEARCH ALGORITHMS

AI problem solving involves designing algorithms to systematically find solutions. The source describes search algorithms as methods that navigate problem spaces to find solutions.

---

# 5.1 Problem Formulation

An AI problem can be represented using:

1. Initial state
2. Actions
3. Transition model
4. Goal state
5. Path cost

---

# 5.2 State Space

A state space contains possible configurations of a problem.

Example: route planning.

States may represent:

* Kampala
* Entebbe
* Jinja
* Mukono
* Mbale

Actions represent possible movements between locations.

---

# 5.3 Agents and Environments

An agent perceives an environment and takes actions to achieve goals.

A simple model is:

**Environment → Perception → Agent → Action → Environment**

---

# 5.4 Breadth-First Search

BFS explores nodes level by level.

It generally uses a queue.

### Properties

* Complete under standard assumptions
* Optimal for equal step costs
* Can consume significant memory

---

# 5.5 Depth-First Search

DFS explores deeply before backtracking.

It generally uses:

* Stack
* Recursion

Advantages:

* Low memory compared with BFS in many cases

Limitations:

* May follow an unproductive branch
* Not generally optimal

---

# 5.6 Uniform Cost Search

UCS expands the lowest-cost path.

It is useful when actions have different costs.

---

# 5.7 Bidirectional Search

Search occurs simultaneously:

* Forward from the initial state
* Backward from the goal

The searches attempt to meet.

---

# 5.8 Comparing Search Algorithms

| Algorithm     | Main Strategy    | Strength                         |
| ------------- | ---------------- | -------------------------------- |
| BFS           | Shallowest first | Complete/optimal for equal costs |
| DFS           | Deepest first    | Memory efficient                 |
| UCS           | Lowest path cost | Cost-sensitive                   |
| Bidirectional | Two directions   | Can reduce search depth          |

# WEEK 6 — HEURISTIC AND LOCAL SEARCH

---

# 6.1 Heuristics

A heuristic estimates how close a state is to a goal.

The source defines heuristics as practical problem-solving strategies that may produce satisfactory rather than necessarily optimal solutions.

Let:

$$
h(n)
$$

represent the estimated cost from node \(n\) to the goal.

---

# 6.2 Greedy Best-First Search

Greedy search selects the node with the smallest heuristic:

$$
f(n)=h(n)
$$

It can be fast but is not necessarily optimal.

---

# 6.3 A* Search

A* combines:

* Cost already travelled
* Estimated remaining cost

$$
f(n)=g(n)+h(n)
$$

where:

* \(g(n)\) = cost from start
* \(h(n)\) = estimated cost to goal

A* is widely used for route planning and pathfinding.

---

# 6.4 Local Search

Local search operates on a current state and attempts to improve it by exploring neighbouring states.

Applications:

* Scheduling
* Optimization
* Timetabling
* Layout optimization

---

# 6.5 Hill Climbing

Hill climbing repeatedly moves to a better neighbouring state.

Problem:

It can become trapped in:

* Local maxima
* Plateaus
* Ridges

---

# 6.6 Simulated Annealing

Simulated annealing sometimes accepts worse solutions early in the search.

The probability of accepting a worse state can decrease as temperature decreases.

This helps escape local optima.

---

# 6.7 Local Beam Search

Maintains multiple candidate states simultaneously.

Instead of one current state, it maintains \(k\) states.

---

# 6.8 Adversarial Search

Used where agents compete.

Examples:

* Chess
* Checkers
* Tic-tac-toe

The source identifies minimax and alpha-beta pruning as major adversarial-search methods.

---

# 6.9 Minimax

There are two players:

* MAX
* MIN

MAX tries to maximize utility.

MIN tries to minimize utility.

---

# 6.10 Alpha-Beta Pruning

Alpha-beta pruning eliminates branches that cannot affect the final decision.

It can significantly reduce the number of nodes evaluated by minimax.

---

# 6.11 Constraint Satisfaction Problems

A CSP contains:

* Variables
* Domains
* Constraints

Examples:

* Timetabling
* Map colouring
* Sudoku
* Scheduling

The source defines CSPs as problems in which variables have possible values and constraints restrict valid combinations.

# 7.8 Expert System Architecture

# 7.9 Rules

Rules are commonly expressed as:

**IF condition THEN conclusion**

Example:

IF

* temperature is high
* soil moisture is low

THEN

* irrigation is required.

---

# 7.10 Forward Chaining

Forward chaining starts from available facts and applies rules until a conclusion is reached.

Example:

Fact:

> Patient has fever.

Rule:

> IF patient has fever AND cough THEN possible infection.

---

# 7.11 Backward Chaining

Backward chaining starts with a goal and works backwards to find supporting facts.

Example:

Goal:

> Does the patient have disease X?

The system searches for rules that could establish disease X, then checks whether their conditions are satisfied.

# WEEK 8 — REASONING, UNCERTAINTY AND FUZZY LOGIC

Reasoning allows AI systems to derive conclusions from available information. Planning determines sequences of actions to achieve goals.

---

# 8.1 Deductive Reasoning

Moves from general rules to specific conclusions.

Example:

All humans are mortal.

John is human.

Therefore:

John is mortal.

---

# 8.2 Inductive Reasoning

Moves from specific observations toward general patterns.

Example:

Observed many birds flying.

Conclusion:

Birds generally fly.

The conclusion is probable rather than guaranteed.

---

# 8.3 Abductive Reasoning

Abduction seeks the most plausible explanation.

Example:

Observation:

> The ground is wet.

Possible explanation:

> It may have rained.

Other explanations may exist.

---

# 8.4 Planning

Planning determines actions required to reach a goal.

Example:

Goal:

> Deliver package.

Possible sequence:

1. Pick package.
2. Load vehicle.
3. Navigate.
4. Arrive.
5. Deliver package.

---

# 8.5 Uncertainty

Real-world information may be:

* Incomplete
* Noisy
* Ambiguous
* Inaccurate
* Conflicting

AI therefore needs mechanisms for reasoning under uncertainty.

---

# 8.6 Probabilistic Reasoning

Probability represents uncertainty mathematically.

$$
0 \leq P(A) \leq 1
$$

Bayes' theorem:

$$
P(A|B)=\frac{P(B|A)P(A)}{P(B)}
$$

where:

* \(P(A|B)\) = probability of A given B
* \(P(B|A)\) = probability of B given A
* \(P(A)\) = prior probability
* \(P(B)\) = evidence

---

# 8.7 Fuzzy Logic

Fuzzy logic is useful for representing degrees of truth.

Traditional logic:

> Temperature is high = TRUE/FALSE.

Fuzzy logic:

> Temperature is high = 0.8.

---

# 8.8 Fuzzy Sets

A fuzzy set assigns a membership value:

$$
\mu_A(x) \in [0,1]
$$

Example:

A temperature of 30°C may have:

$$
\mu_{Hot}(30)=0.7
$$

---

# 8.9 Linguistic Variables

A variable can be described using linguistic terms.

**Temperature**

* Cold

* Hot

---

# 8.10 Membership Functions

Common shapes include:

* Triangular
* Trapezoidal
* Gaussian

---

# 8.11 Fuzzy Rules

Example:

IF temperature is high
AND humidity is low
THEN fan speed is high.

---

# 8.12 Fuzzy Inference

Typical process:

1. Fuzzification
2. Rule evaluation
3. Aggregation
4. Defuzzification

---

# 8.13 Defuzzification

Converts a fuzzy output into a numerical value.

Example:

Fuzzy result:

> Fan speed = low/medium/high

Defuzzification:

> Fan speed = 72%

---

# 8.14 Fuzzy Logic vs Probability

| Fuzzy Logic                | Probability                      |
| -------------------------- | -------------------------------- |
| Degree of membership/truth | Degree of uncertainty            |
| "How hot is it?"           | "What is probability it is hot?" |
| Uses membership functions  | Uses probability distributions   |

# 9.3 Linear Regression

A simple model:

$$
y = mx+b
$$

For multiple variables:

$$
y=\beta_0+\beta_1x_1+\beta_2x_2+\cdots+\beta_nx_n
$$

---

# 9.4 Logistic Regression

Used for classification.

The sigmoid function is:

$$
\sigma(z)=\frac{1}{1+e^{-z}}
$$

The output lies between 0 and 1.

---

# 9.5 Decision Trees

A decision tree makes predictions using a sequence of decisions.

Example:

```text
Income?
 ├── High → Approve
 └── Low
      ├── Good credit → Approve
      └── Poor credit → Reject
```

---

# 9.6 Support Vector Machines

SVM attempts to find a decision boundary that separates classes.

The objective is generally to maximize the margin between classes.

---

# 9.7 Random Forests

A random forest combines multiple decision trees.

Advantages:

* Robust
* Good generalization
* Handles nonlinear relationships
* Useful for classification and regression

---

# 9.8 Clustering

Clustering groups similar observations.

---

# 9.9 K-Means

Steps:

1. Select \(k\).
2. Initialize centroids.
3. Assign points to nearest centroid.
4. Recalculate centroids.
5. Repeat until convergence.

---

# 9.10 PCA

Principal Component Analysis reduces dimensionality while attempting to preserve important variation.

Uses include:

* Visualization
* Noise reduction
* Feature reduction

---

# 9.11 Hierarchical Clustering

Creates a hierarchy of clusters.

It can be represented using a dendrogram.

---

# 9.12 DBSCAN

DBSCAN groups points based on density.

It can identify noise and does not require specifying the number of clusters in advance.

---

# 9.13 Reinforcement Learning

Important components:

* Agent
* Environment
* State
* Action
* Reward
* Policy

---

# 9.14 Markov Decision Process

An MDP can be represented by:

$$
(S,A,P,R,\gamma)
$$

where:

* \(S\) = states
* \(A\) = actions
* \(P\) = transition probabilities
* \(R\) = rewards
* \(\gamma\) = discount factor

---

# 9.15 Bellman Equation

A simplified value relationship is:

$$
V(s)=\max_a [R(s,a)+\gamma V(s')]
$$

---

# 9.16 Q-Learning

Q-learning learns action values.

The update rule is:

$$
Q(s,a)\leftarrow Q(s,a)+
\alpha[r+\gamma\max_{a'}Q(s',a')-Q(s,a)]
$$

---

# 9.17 Deep Q-Networks

DQN uses neural networks to approximate Q-values.

# WEEK 10 — DEEP LEARNING AND NEURAL NETWORKS

Deep learning uses neural networks with multiple layers to learn complex representations.

---

# 10.1 Artificial Neuron

A neuron receives inputs:

$$
x_1,x_2,\ldots,x_n
$$

Each input has a weight:

$$
w_1,w_2,\ldots,w_n
$$

The weighted sum is:

$$
z=\sum_i w_ix_i+b
$$

The activation function produces:

$$
a=f(z)
$$

---

# 10.2 Neural Network Architecture

A basic neural network contains:

1. Input layer
2. Hidden layers
3. Output layer

---

# 10.3 Activation Functions

### Sigmoid

$$
\sigma(x)=\frac{1}{1+e^{-x}}
$$

### ReLU

$$
ReLU(x)=\max(0,x)
$$

### Tanh

$$
\tanh(x)
$$

---

# 10.4 Multi-Layer Perceptron

An MLP contains multiple layers of neurons.

It can learn nonlinear relationships.

---

# 10.5 Forward Propagation

Data moves:

**Input → Hidden Layers → Output**

---

# 10.6 Loss Function

A loss function measures how wrong a model's prediction is.

Examples:

* Mean Squared Error
* Cross-Entropy Loss

---

# 10.7 Backpropagation

Backpropagation calculates gradients of the loss with respect to model parameters.

The parameters are then updated using optimization algorithms.

---

# 10.8 Gradient Descent

General update:

$$
\theta \leftarrow \theta-\alpha\nabla_\theta L
$$

where:

* \(\theta\) = model parameters
* \(\alpha\) = learning rate
* \(L\) = loss

---

# 10.9 Overfitting

Overfitting occurs when a model learns training data too closely, including noise, and performs poorly on new data.

---

# 10.10 Underfitting

Underfitting occurs when the model is too simple to capture the underlying pattern.

---

# 10.11 Convolutional Neural Networks

CNNs are especially useful for images.

Main components:

* Convolution
* Filters/kernels
* Feature maps
* Activation
* Pooling
* Fully connected layers

---

# 10.12 Recurrent Neural Networks

RNNs process sequential information.

Applications:

* Text
* Speech
* Time series

---

# 10.13 LSTM and GRU

LSTM and GRU architectures help model longer-term dependencies in sequential data.

# GLOSSARY OF IMPORTANT TERMS

**Artificial Intelligence:** Technology for creating systems capable of performing tasks associated with intelligence.

**Machine Learning:** AI approach in which systems learn patterns from data.

**Deep Learning:** Machine learning based on multi-layer neural networks.

**Algorithm:** Step-by-step procedure for solving a problem.

**Agent:** Entity that perceives an environment and acts toward goals.

**Environment:** Context in which an agent operates.

**Training Data:** Data used to train a model.

**Model:** Mathematical representation learned from data.

**Overfitting:** Learning training data too closely, including noise.

**Underfitting:** Model is too simple to capture underlying patterns.

**Heuristic:** Practical estimate or strategy used to guide problem solving.

**Expert System:** Rule/knowledge-based system that emulates specialist decision-making.

**Fuzzy Logic:** Logic that represents degrees of truth or membership.

**Computer Vision:** AI concerned with interpreting visual information.

**YOLO:** Real-time object-detection model family.

**NLP:** AI field concerned with processing human language.

**LLM:** Large language model trained on large quantities of language data.

**Generative AI:** AI capable of generating new content such as text, images or music.

**RAG:** Retrieval-Augmented Generation, combining information retrieval with generative models.

**AI Agent:** Software or hardware entity capable of autonomous actions toward goals.

**Agentic AI:** AI systems designed to pursue goals through multi-step reasoning and action.

**Sensor:** Device that measures information from an environment.

**Actuator:** Device that converts control signals into physical action.

**IoT:** Network of connected physical devices.

**IoRT:** Internet of Robotic Things, integrating robotics, IoT, AI and networked devices.

**Edge AI:** AI processing performed close to the data source.

**Cloud AI:** AI workloads performed using cloud computing infrastructure.

**Autonomous System:** System capable of operating independently with limited human intervention.
